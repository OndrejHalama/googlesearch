# Citace a zdroje

## Zadani a reference

- CS50's Web Programming with Python and JavaScript, Project 0: Search. Zadani a specifikace vyhledavaciho rozhrani, parametru GET a pokrocileho vyhledavani: <https://cs50.harvard.edu/web/projects/0/search/>.
- Google Search, cilovy vyhledavac formularu: <https://www.google.com/search>.
- W3C Nu HTML Checker, odkaz na validaci HTML jednotlivych stranek: <https://validator.w3.org/nu/>.
- W3C CSS Validation Service, odkaz na validaci pouziteho CSS: <https://jigsaw.w3.org/css-validator/>.
- Portfolio autora: <https://ondrejhalama.github.io/portfolio/>.

## Pouzite AI prompty

- „Navrhněte front-end pro Google Search, Google Image Search a Google Advanced Search.“ Uzivatelske zadani dale obsahovalo pozadavky na tri vyhledavaci stranky, GET parametry, vzhled a tlacitko „I'm Feeling Lucky“.
- „Vytvořte další stránku v rámci výše uvedeného projektu, která bude obsahovat co největší množství formulářových prvků (input, select, checkbox, radio, textarea, button, ...).“
- „Na všech stránkách projektu budou 2 odkazy na validaci HTML a CSS. Odkazy budou směřovat na validátory [...] nastavené tak, aby validovaly kód dané stránky.“
- „Na všech stránkách projektu bude odkaz na soubor obsahující citace a zdroje, které jste použili při tvorbě projektu. [...] Citace obsahují použité prompty.“
- „V rámci google search projektu budete mít i odkaz na své portfolio.“
